# Git HOL-002 – Git Ignore

## Objective
- Understand the purpose of .gitignore.
- Ignore unwanted files and folders from version control.

## Repository
GitDemo

## Commands Covered
- git status
- touch
- git add
- git commit
- git push

## Files Created
- .gitignore
- error.log (ignored)
- log/ folder (ignored)

## .gitignore Rules
text
*.log
log/


## Result
Configured Git to ignore all .log files and the log directory. Only the required project files were committed to GitHub.
